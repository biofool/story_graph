# Component: Graph DB

**Path:** `src/storage/graph_db.py` (382 LOC)
**Type:** Core infrastructure — persistence layer

## Responsibility

SQLite-backed property graph store. Manages four tables (`nodes`, `edges`,
`sources`, `claim_sources`) with add/upsert/query operations. All other
components that need persistence depend on this class.

## Interface

```python
class GraphDB:
    def __init__(self, db_path: str | Path)
    def close(self) -> None
    # Node operations
    def add_node(self, node: GraphNode) -> None      # upsert by id
    def get_node(self, node_id: str) -> GraphNode | None
    def get_nodes_by_type(self, node_type: NodeType) -> list[GraphNode]
    # Edge operations
    def add_edge(self, edge: GraphEdge) -> None       # INSERT OR IGNORE
    def get_edges_from(self, node_id: str) -> list[GraphEdge]
    def get_edges_to(self, node_id: str) -> list[GraphEdge]
    def get_all_edges(self) -> list[GraphEdge]
    # Source operations
    def add_source(self, source: SourceRecord) -> None  # upsert by id
    def get_source_by_url(self, url: str) -> SourceRecord | None
    def get_source(self, source_id: str) -> SourceRecord | None
    def get_all_sources(self) -> list[SourceRecord]
    # Claim-source links
    def add_claim_source_link(self, link: ClaimSourceLink) -> None
    # Query helpers
    def get_claims_about(self, node_id: str) -> list[GraphNode]
    def get_persons_connected_to_group(self, group_label_substr: str) -> list[tuple[str, str]]
    def get_contradictions(self) -> list[tuple[str, str]]
    # Counts
    def get_node_count(self) -> int
    def get_edge_count(self) -> int
    def get_source_count(self) -> int
    # Context manager
    def __enter__(self) -> GraphDB
    def __exit__(...) -> None  # calls close()
```

## State/Data

- SQLite file at `db_path` (default: `data/graph.db`)
- Connection stored in `self._conn` (single connection, no pooling)
- `_get_conn()` guard raises `RuntimeError("GraphDB is closed")` if used
  after `close()` (OBSERVED: added in fix/priority-items merge)

## Boundaries

- No FK enforcement between edges and nodes
- No transaction batching — each operation commits individually
- No concurrent access support (single sqlite3 connection)
- Schema is additive only (`CREATE TABLE IF NOT EXISTS`)

## Change Guidance

- **Schema changes:** Must update `SCHEMA_SQL`. Existing DBs won't migrate
  (no ALTER TABLE). Consider backward compatibility or DB rebuild.
- **Enum changes in `models.py`:** `NodeType`/`RelationType` values are
  stored as TEXT in DB. Adding values is safe; removing/renaming breaks
  existing data.
- **ID format changes:** Node IDs are generated by `alias_resolver.py`
  functions. Changing the format invalidates existing graph databases.
- **Adding query methods:** Safe — add new methods, existing callers
  unaffected. Add corresponding tests in `tests/unit/test_graph_db.py`.
