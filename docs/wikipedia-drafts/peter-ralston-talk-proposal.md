- **WP:V** — every factual sentence carries an inline citation to a
  source that supports that exact claim; quotes are quoted in the source.
- **WP:NOR** — no synthesis; the Enter-the-Dragon comparison is the
  source's own framing, attributed.
- **WP:NPOV / WP:BLP** — no superlatives in the article's voice; "the
  Asian martial arts world was stunned" appears only as attributed
  quotation; birth year omitted as underdetermined rather than guessed.
- **WP:RS** — notability rests on edited magazines; self-pub sources
  carry only uncontroversial detail; Wikipedia is never cited.
