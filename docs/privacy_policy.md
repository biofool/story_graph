# Privacy Policy — Source Family Public Page Research

**Last Updated:** August 2026  
**Application Name:** Source Family Public Page Research  
**Contact:** research@storygraph.local

## 1. Overview
The **Source Family Public Page Research** application is an academic and historical research project dedicated to documenting and analyzing the public history, media discourse, and biographical claims related to The Source Family and Father Yod (James Edward Baker).

## 2. Information We Access
Our application accesses data exclusively through official Meta Graph API endpoints:
- Public Facebook Page metadata (Page Name, Page ID).
- Public posts and comments on designated public Facebook Pages (Post ID, Timestamp, Public message/caption text, Public permalink URL).
- Public engagement metrics (e.g. comment counts, reaction totals) necessary for historical provenance verification.

**What We Do NOT Collect:**
- We do not access private user profiles, friend lists, private groups, direct messages, or restricted content.
- We do not collect passwords, session cookies, payment info, or private contact details.
- We do not track or profile individual private users.

## 3. How Information Is Used
Data retrieved via Meta's Graph API is used solely for:
- Historical entity extraction and citation tracking.
- Contradiction detection and source provenance analysis.
- Maintaining an academic property graph of public claims and publications.

We do not sell, rent, or monetize any data obtained through Meta APIs.

## 4. Data Storage & Security
- Retrieved public text excerpts and citations are stored in a secure, local SQLite database with access restricted to authorized researchers.
- Data is retained only as long as necessary for scholarly evaluation and source provenance verification.

## 5. User Data Deletion & Inquiries
Anyone wishing to request the deletion or correction of any referenced public data can submit a request following our [Data Deletion Instructions](./data_deletion.md) or by emailing the contact address listed above.
